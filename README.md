# Chess AI Engine

A lightweight Python chess engine implementing static material evaluation and depth-limited minimax search.

## Setup

1. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running Tests

Run the test suite using `pytest`:

```bash
pytest
```

Or using the virtualenv Python directly:

```bash
.venv/bin/pytest
```
